# 专注出口（Chrome / Edge 扩展）

**B站全站拦截**：首页、视频、搜索、动态、个人空间、b23.tv 短链，一打开就跳到信息台的「先停一下」页：
https://prima-bottle.github.io/info-feed/focus/

没有放行按钮。唯一的例外是 `whitelist.json` 里的 UP 主：他们的视频页和个人空间能打开（视频页右侧推荐会被隐藏）。白名单默认是空的；要加谁，告诉 Claude。

想看东西的时候，「先停一下」页会把你带到扩展里的**德语剧播放器**，播放桌面「剧集研究」文件夹里的剧。

## 安装

**Chrome**
1. 把仓库下载到电脑上（GitHub 页面 → Code → Download ZIP，解压），或 `git clone`
2. 地址栏打开 `chrome://extensions`
3. 右上角打开「开发者模式」
4. 点「加载已解压的扩展程序」，选 `focus-extension` 这个文件夹

**Edge**
1. 同上，先把仓库下载到电脑上
2. 地址栏打开 `edge://extensions`
3. 左下角打开「开发人员模式」
4. 点「加载解压缩的扩展」，选 `focus-extension` 文件夹

装好后点一下浏览器右上角的拼图图标，把「专注出口」固定出来。

以后仓库里的扩展有更新：重新下载/`git pull`，然后在扩展页点这个扩展的 ↻ 刷新按钮。

## 「先停一下」页做什么

- **下一步卡片**：正在做什么、这一段的终点、2 分钟内能开始的第一步。可以从信息台「工作」里今天的安排直接选。
- **按原因分流**
  - 刚坐下进不去 → 只显示第一步，5 分钟后弹系统通知提醒
  - 卡住了 → 一句话写下卡在哪，可一键复制去问 Claude，或直接设为下一步
  - 累了 / 枯燥 → 离开屏幕 5 或 15 分钟，到时响一声
  - 想奖励自己 / 就是想看点东西 → 看一集德语剧
  - 要找一个具体的视频 → 记下来；做事要用的教程，让 Claude 把 UP 主加进白名单
- **这一周的记录**：每次被拦记一条原因、有没有转去看剧；可以复制发给 Claude 一起复盘。

## 德语剧播放器

- 第一次打开时点「选择剧集文件夹」，选桌面上的 **剧集研究**。之后会记住；浏览器有时会要求再点一下授权，弹窗里选「每次访问时都允许」就不用再点。
- 每个子文件夹算一季（例如「巴比伦柏林S02」），里面的 mp4 按集数排序。
- 自动从上次停下的地方接着放；看完一集停在「这一集看完了」，不会自动播下一集。
- 和视频同名的 `.srt` / `.vtt` 字幕会自动加载（例如 `xxx.mp4` 配 `xxx.srt` 或 `xxx.de.srt`）。
- 快捷键：空格 播放/暂停，← / → 后退/前进 5 秒，S 字幕开关，Esc 回到剧集列表。
- 扩展图标弹窗里也有「▶ 看一集德语剧」。

## 加白名单 UP 主

`whitelist.json` 的格式：

```json
{ "ups": [ { "mid": 123456, "name": "某个教程 UP 主" } ] }
```

`mid` 是 UP 主个人空间地址 `space.bilibili.com/123456` 里的数字。改完后在扩展页点 ↻ 重新加载。

## 文件

| 文件 | 作用 |
|---|---|
| `rules.json` | 把整个 B站重定向到「先停一下」页 |
| `whitelist.json` | 白名单 UP 主 |
| `player.*` | 德语剧播放器 |
| `background.js` | 按白名单生成放行规则、提醒通知、打开播放器、关闭标签页 |
| `bili.js` | 第二道关：核对视频页的 UP 主是否在白名单；隐藏推荐 |
| `relay.js` | 「先停一下」页和扩展之间传话 |
| `popup.*` | 扩展图标弹窗：状态、看剧入口、隐藏推荐开关 |

B站改版后，隐藏推荐用的类名可能失效；失效时告诉 Claude 更新 `bili.js` 里的选择器。
