# 专注出口（Chrome / Edge 扩展）

点开 B站**首页、热门、分区页**时，自动跳到信息台的「先停一下」页：
https://prima-bottle.github.io/info-feed/focus/

搜索页、视频页、动态页都照常能打开，真想看某个视频时不受影响；视频页右侧的推荐列表和播放结束后的推荐会被隐藏（可在扩展图标里关掉）。

## 安装

**Chrome**
1. 把仓库下载到电脑上（GitHub 页面 → Code → Download ZIP，解压），或 `git clone`
2. 地址栏打开 `chrome://extensions`
3. 右上角打开「开发者模式」
4. 点「加载已解压的扩展程序」，选 `focus-extension` 这个文件夹

**Edge**
1. 同上，先把仓库下载到电脑上
2. 地址栏打开 `edge://extensions`
3. 左下角打开「开发人员模式」
4. 点「加载解压缩的扩展」，选 `focus-extension` 文件夹

装好后点一下浏览器右上角的拼图图标，把「专注出口」固定出来。

以后仓库里的扩展有更新：重新下载/`git pull`，然后在扩展页点这个扩展的 ↻ 刷新按钮。

## 「先停一下」页做什么

- **下一步卡片**：正在做什么、这一段的终点、2 分钟内能开始的第一步。可以从信息台「工作」里今天的安排直接选（密码和信息台一样，这台电脑上输一次会记住）。
- **四个原因分流**
  - 刚坐下进不去 → 只显示第一步，5 分钟后弹系统通知提醒
  - 卡住了 → 一句话写下卡在哪，可一键复制去问 Claude，或直接设为下一步
  - 累了 / 枯燥 → 离开屏幕 5 或 15 分钟，到时响一声
  - 想奖励自己 → 看信息台精选、搜一个具体视频，或放行 10 分钟
  - 就是想刷 → 等 30 秒，再放行 10 分钟，到点自动恢复拦截
- **这一周的记录**：每次被拦记一条原因，按原因和钟点统计；可以复制发给 Claude 一起复盘。

记录只存在这台电脑这个浏览器里（Chrome 和 Edge 各存各的）。

## 文件

| 文件 | 作用 |
|---|---|
| `rules.json` | 把首页/热门/分区页重定向到「先停一下」页 |
| `background.js` | 放行计时、提醒通知、关闭标签页 |
| `bili.js` | 站内跳转的兜底拦截；视频页隐藏推荐 |
| `relay.js` | 「先停一下」页和扩展之间传话 |
| `popup.*` | 扩展图标弹窗：状态、隐藏推荐开关 |

B站改版后，隐藏推荐用的类名可能失效；失效时告诉 Claude 更新 `bili.js` 里的选择器。
