《希望》竞选海报（Obama "Hope" poster）

谢泼德·费尔雷（Shepard Fairey） · 2008

它要解决什么问题

2008年美国总统选举期间，街头艺术家费尔雷想用一张能迅速复制、在街头张贴的海报，把一位当时知名度有限的候选人变成一个“符号”。受众是年轻选民和街头路人，要的是一眼能记住、能被大量转发和模仿的形象。这张海报最初是他自发制作的，后来被竞选阵营接受并广泛使用。

创作者的关键决定

  1. 构图：把人物放成侧脸仰视的半身像，视线朝上，给人“望向未来”的感觉，比正面照更有方向感。
  2. 色彩：只用红、米白、深蓝和浅蓝几种颜色，类似丝网印刷，减少层次后更容易在复印、贴墙和印刷时保持辨识度。
  3. 字体：底部用大写无衬线单词（HOPE、PROGRESS、CHANGE），字很大、很少，只留一个口号，让人记住的是词而不是长句。
  4. 媒介：把一张照片转成接近版画的平涂块面，既像政治宣传画，又像街头艺术，能同时被政治圈和艺术圈接受。

符号怎么用

红白蓝呼应美国国旗；人物头像的处理方式借自苏联和构成主义宣传画、街头海报的传统，但内容从“权威、动员”转为“希望、变化”，是对旧宣传语言的反转使用。单词口号化也让海报能被别人改写成其他内容（后来出现大量模仿版本）。

你可以借用的手法

  • 每张海报只讲一个词或一句话，字要大到手机缩略图里也能读。
  • 把照片压缩成3到4种颜色的块面，去掉细节，保留脸部明暗的主要分界。
  • 让人物视线朝上或朝远处，表达“方向”和“期待”，比正视镜头更适合做政治或历史主题。
  • 借用旧宣传画的版式，但把文案和情绪反转，比如把“号召服从”改成“号召质疑”，对德国学生有话题性。
