  1. 借用医学 X 光片的形式：把人体画成透视图，「透视」本身就暗示真相被看穿，观者不需要读文字就知道这是在揭露。
  2. 把吞下去的金币堆在脊柱的位置：金钱成了他的骨架，视觉上直接回答「靠什么站着」，隐喻很具体，不靠象征学知识。
  3. 保留演讲者举臂的姿势，让这个人物一看就能认出，同时把他放进 X 光的冷静科学语境里，形成荒诞反差。
  4. 标题用文字游戏：Blech 既指金属（废铁、铁皮），又是「废话」的俗语。一句话把「吞金」和「空话」对在一起。
  5. 媒介选择照片蒙太奇和黑白印刷：照片带来可信度，拼贴带来荒诞，印刷粗粝反而适合大量发行。

符号怎么用

金币、X 光片和举臂姿势都是现成符号，哈特菲尔德没有发明新符号，而是把它们放到不匹配的语境里：权力人物的形象被改造成一个被金钱「填充」的躯壳，把原本用来制造崇拜的姿势反转为揭露的证据。

你可以借用的手法

  • 一张海报只放一个「揭露」概念，比如透视、解剖、剖面图，让观众一眼读懂。
  • 用一个冷静的科学或技术视觉形式（X 光、示意图、说明书）去装一个政治内容，反差本身就是力量。
  • 标题写成双关语，并让文字和图像各自说一半，观众合起来才完整。
  • 颜色克制：黑白加一个强调色，让文字区域留白，适合手机屏幕上小尺寸阅读。
  • 做德语 Instagram 帖子时，可以把这种「透视」手法用于解释政治话题，比如一份预算的资金流向。
